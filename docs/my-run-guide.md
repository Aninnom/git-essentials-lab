# Run Guide

## Prerequisites
- Python 3.9 or later
- JDK 17 or later

## Run
```bash
python3 run.py demo
```

## What the demo does
Runs a library loan scenario on a fixed date (2026-09-01). It prints the student and faculty loan limits, searches the catalog for "git", lends "Git Essentials" to Alex with a 14-day due date, returns it, and prints the return fee and the number of active loans.
